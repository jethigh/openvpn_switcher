# Project Workflow Protocols

**Assisted-by**: Antigravity [Gemini 3.8 Flash (High)]  

These protocols govern the execution and tracking flow across all orchestration stages:

1. **Plan Commitment**:
   - Once an architectural plan is agreed upon or substantially revised, commit `.agents/plan.md` (and related configuration) and push to remote.
2. **Audit Tracking**:
   - Every formal audit report generated by Simplicio (`.agents/audit.md`) must be committed.
3. **Step Completion Commitment**:
   - Upon completing and verifying each atomic step in `.agents/plan.md` (after Simplicio approval), commit the implementation, unit tests, and updated plan, and push to remote.
4. **Lifecycle Repetition**:
   - Repeat points 2 and 3 sequentially for every step until the plan is fully delivered.
5. **Git Commit Standards**:
   - Messages must be strictly in English.
   - Every commit must include the structured co-authorship trailer:
     `Co-authored-by: Antigravity <antigravity@google.com>`
